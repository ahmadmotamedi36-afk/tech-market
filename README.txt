TECH MARKET — Django MVP برای انتشار روی Render
================================================

این بسته یک MVP اجرایی برای مدل فعلی TECH Market است: معرفی و جست‌وجوی محصولات،
فیلتر دسته‌بندی و مرتب‌سازی، صفحه محصول، لینک به فروشگاه مقصد، ثبت‌نام/ورود،
علاقه‌مندی‌ها، فرم درخواست همکاری فروشندگان و پنل مدیریت Django.

مهم: این نسخه بازارگاه کامل چندفروشنده‌ای با پرداخت و سفارش نیست. خرید در سایت
فروشنده مقصد انجام می‌شود. پنل مستقل فروشنده برای ثبت مستقیم کالا، پرداخت آنلاین،
سیستم سفارش/ارسال/مرجوعی، پیامک/ایمیل تراکنشی و بازیابی رمز ایمیلی در این نسخه وجود ندارد.

راه‌اندازی محلی (Windows):
1) Python 3.11+ نصب باشد.
2) داخل پوشه پروژه CMD باز کنید.
3) python -m venv .venv
4) .venv\Scripts\activate
5) pip install -r requirements.txt
6) فایل .env.example را به .env کپی کنید و SECRET_KEY امن و مقادیر محلی را تنظیم کنید.
7) python manage.py migrate --run-syncdb
8) python manage.py createsuperuser
9) python manage.py runserver
سایت: http://127.0.0.1:8000
مدیریت: http://127.0.0.1:8000/admin/

انتشار رایگان آزمایشی روی Render:
1) یک مخزن GitHub بسازید و تمام محتویات این پوشه را در ریشه مخزن قرار دهید.
2) در Render گزینه New > Blueprint را انتخاب و مخزن را متصل کنید؛ render.yaml سرویس را تعریف می‌کند.
3) برای DATABASE_URL یک PostgreSQL پایدار از ارائه‌دهنده‌ای مانند Neon بسازید و آدرس اتصال را در Environment سرویس Render قرار دهید.
   آدرس باید با postgresql:// شروع شود و SSL را فعال داشته باشد.
4) پس از Build موفق، در Shell سرویس اجرا کنید: python manage.py createsuperuser
5) آدرس ساخته‌شده با پسوند onrender.com را باز کنید و از /admin/ وارد مدیریت شوید.
6) در پنل مدیریت ابتدا دسته‌بندی و سپس محصولات را اضافه کنید. برای هر محصول نام فروشگاه و لینک قانونی صفحه محصول را وارد کنید.

نکات Render رایگان:
- سرویس رایگان وب ممکن است پس از مدتی بی‌استفاده‌ماندن به حالت خواب برود و درخواست اول بعدی کندتر باشد.
- سهمیه و شرایط پلن رایگان سرویس‌ها تغییر می‌کند؛ پیش از استفاده، قیمت و محدودیت‌های روز را بررسی کنید.
- از SQLite روی فضای موقت هاست ابری برای داده‌های اصلی استفاده نکنید؛ DATABASE_URL را به PostgreSQL پایدار متصل کنید.
- دامنه اختصاصی اختیاری است؛ ابتدا زیردامنه ارائه‌شده را آزمایش کنید.

مدیریت سایت:
- /admin/ مدیریت محصولات، دسته‌ها، کاربران و درخواست‌های فروشندگان
- /register/ ثبت‌نام کاربر
- /login/ ورود
- /seller/apply/ فرم درخواست همکاری فروشندگان
- /health/ بررسی سلامت سرویس

چک‌لیست پیش از استفاده عمومی:
- متن قوانین و حریم خصوصی را مطابق محل فعالیت، روش جمع‌آوری داده و مقررات مربوطه بازبینی و تکمیل کنید.
- فقط عکس، توضیحات، قیمت و لینک‌هایی را منتشر کنید که مجوز استفاده از آن‌ها را دارید؛ قوانین برنامه‌های همکاری در فروش را رعایت کنید.
- قیمت و موجودی ممکن است تغییر کند؛ روش به‌روزرسانی منظم و اعلام تاریخ آخرین بررسی را اضافه کنید.
- پشتیبان‌گیری پایگاه داده، محدودیت ضداسپم، مانیتورینگ، بازیابی رمز و ایمیل تراکنشی را پیش از جذب کاربر زیاد تکمیل کنید.
- کلید SECRET_KEY و رمز مدیر را محرمانه نگه دارید و هرگز در GitHub قرار ندهید.
- پیش از دریافت اطلاعات واقعی کاربران یا پرداخت، بررسی امنیتی و حقوقی مستقل انجام دهید.

این پروژه برای استقرار نیازمند حساب میزبانی و تنظیم متغیرهای محیطی است؛ هیچ فایل ZIP
نمی‌تواند بدون اتصال به سرویس میزبانی، خودش دامنه و سرور اینترنتی ایجاد کند.
